feat: HLS subtitles & multi-audio renditions, senior refactor, 137 tests + CI

New version of the Adaptive HLS Orchestrator: subtitle extraction in HLS,
multi-audio renditions for anime dubs, senior-level refactor (junior-readable),
full test suite and GitHub Actions CI. Banner command and artifacts unchanged.

FEAT
- Subtitles in HLS: text tracks (SRT/ASS/SSA/MOV_TEXT) are converted to WebVTT
  and published as EXT-X-MEDIA:TYPE=SUBTITLES renditions (subtitles/<lang>/);
  image-based PGS/DVB tracks are skipped with a warning.
  Flags: --subs-enabled (on by default), --subs-languages, --subs-default-language.
- Multi-audio in HLS: every dub track becomes a separate rendition
  (EXT-X-MEDIA:TYPE=AUDIO, audio/<lang>/); video variants are now video-only,
  the player mixes audio/subtitles on the fly (switch dubs without reload).
  Flags: --audio-languages, --audio-default-language.
- CLI: --input/-i flag form (the banner command works verbatim); boolean flags
  accept explicit values (--poster-enabled true); master playlist default
  renamed to master.m3u8 (as on the product banner); exit codes 0/1/2.

REFACTOR
- Exception -> ProcessingException: no more java.lang.Exception shadowing.
- Single ffprobe pass per run; OptionsNormalizer no longer mutates option
  copies and returns an immutable EncodingProfile (parallel-list hell removed).
- FFmpeg command strategies per processing type; -y/-nostdin in every command;
  processes always destroyed; non-zero exit errors carry the output tail.
- Comments/javadoc are fully Russian (team agreement); logs stay English.

FIX
- --all-audio-tracks never worked (audioStreams were not populated) - fixed.
- "-map null" in audio mapping; zero-width crash with --no-audio; poster
  ignored --poster-filename; BANDWIDTH was kbps instead of bits/sec;
  dangling AUDIO="audio" group without EXT-X-MEDIA; -metas:a:0 typo;
  variant folder/URI mismatch for custom names.

TEST / CI
- 137 JUnit 5 tests incl. E2E pipeline run on fake ffprobe/ffmpeg;
  JaCoCo line coverage 98.8% (branch 87.5%), jacoco:check gate LINE>=95/BRANCH>=85;
  lombok.config excludes Lombok boilerplate from coverage metrics.
- GitHub Actions (.github/workflows/ci.yml): Temurin 21, mvn verify,
  artifacts: HLS-1.0.0.jar + JaCoCo report.

CHORE
- dependency-reduced-pom.xml and .idea removed from VCS, .gitignore added.
- Dead ErrorCode/ErrorCategory entries removed; getFirst()/getLast() (Java 21).
